Odoo App

Connect Claude to your Odoo in about two minutes. Then just ask Claude about your customers, sales, invoices, stock and more.

Easiest

One-click extension for Claude Desktop

No terminal. Download, double-click, type your Odoo login.

  1. Make sure Claude Desktop is installed and you are signed in. Already have it? Skip ahead.
  2. Download the Odoo extension

    Then open the downloaded odoo.mcpb file (double-click it in your Downloads folder). Claude opens and shows the extension. Click Install. If it says the extension is unsigned, choose Install anyway.

  3. Fill in your Odoo address (for example https://mycompany.odoo.com), the email you log into Odoo with, and your Odoo password. Leave "Database" empty. Click Save.
  4. Start a new chat and ask:
    Check my Odoo connection

    Claude replies with your Odoo version, company and user name. That is it. From now on ask Claude anything about your Odoo data.

Alternative

Automatic installer (Terminal)

Also connects Claude Code, and verifies your login before finishing. Good for people who do not use Claude Desktop extensions.

  1. Open Terminal: press ⌘ space, type Terminal, press return.
  2. Paste this line and press return:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Raiybo/Odoo-App/main/install.sh)"

    It downloads what it needs (nothing else on your Mac changes), asks for your Odoo address, email and password, checks that they work, connects Claude Desktop and Claude Code, and restarts Claude Desktop.

  3. Open Claude and ask Check my Odoo connection.

What can I ask Claude once it is connected?

Claude sees exactly what you can see in Odoo, nothing more. A few ideas:

  • "Which invoices are overdue, and by how much in total?"
  • "Show me the open quotations for Azure Interior."
  • "How much did each salesperson sell this quarter?"
  • "Which products are below their minimum stock?"
  • "Create a lead for Acme Corp, contact Jane Doe, worth 12,000."
  • "Add a note to sales order S00042 saying the delivery is delayed."
  • "Give me a link to the customer record for Deco Addict."
  • "Explain what fields a sales order has."

Claude asks for your confirmation before it creates, changes or deletes anything. Prefer a strict look-but-don't-touch mode? Turn on Read-only mode in the extension settings.

Something not working?

"Login failed" or "needs an API key"

Use the same email and password you type on the Odoo login page. If your account uses two-factor authentication or you sign in with Google / Microsoft, Odoo does not accept a password from other apps. Create an API key instead: in Odoo click your name (top right) → Preferences → Account Security → New API Key. Paste that key in place of the password.

"Could not determine which database to use"

Rare. The database name is usually the first part of your Odoo address (mycompany for mycompany.odoo.com). On Odoo.sh it is shown in your project. Otherwise ask whoever manages your Odoo. Put it in the Database field of the extension (or in the installer when it asks).

Claude does not seem to know about Odoo

Fully quit Claude Desktop and open it again. Then check Settings → Extensions: "Odoo" should be listed and switched on. In a new chat, the tools menu (the sliders icon) should show Odoo. If you used the Terminal/PowerShell installer, check Settings → Developer for a server named "odoo".

"This extension is unsigned"

Expected: the extension is published by your own team, not through Anthropic's directory. Choose Install anyway. Everything it does is open source in the repository linked below.

Where are my Odoo password and settings stored?

On your computer only. The extension stores the password in your operating system's keychain (Claude Desktop handles that). The installer stores it in a private file that only your user account can read (~/.odoo-claude/config.json on Mac, %LOCALAPPDATA%\OdooClaude\config.json on Windows). Nothing is sent anywhere except directly to your Odoo server.

How do I remove it?

Extension: Settings → Extensions → Odoo → Uninstall. Installer: run the same command again with -- --uninstall at the end (Mac), or on Windows run $env:ODOO_CLAUDE_UNINSTALL='1' first and then the install command.

For IT: what does this actually do?
  • Runs a small local program (open source, no dependencies) that talks to Odoo over HTTPS using the user's own login, through Odoo's standard web API. The connection method is picked automatically (web session, JSON-2 API with an API key on Odoo 19+, or classic JSON-RPC), so it works on Odoo Online, Odoo.sh and self-hosted, version 13 and newer.
  • The user's Odoo access rights apply unchanged. Read-only mode can be forced with ODOO_READ_ONLY=true.
  • Unattended install: set ODOO_URL, ODOO_LOGIN, ODOO_PASSWORD (and ODOO_CLAUDE_NO_LAUNCH=1) before running the installer.
  • Team and Enterprise admins can also upload odoo.mcpb once in the Claude admin console so everyone gets it automatically.
Source code, issues and updates: github.com/Raiybo/Odoo-App. Works with Claude Desktop and Claude Code on macOS and Windows.
