  2. Install the Claude Desktop app.
    Download Claude for Mac(.dmg, works on Apple Silicon and Intel, needs macOS 13 or newer)

2Add Odoo to Claude

One small file teaches Claude how to talk to Odoo. Download it, open it, click Install.

  1. Download the Odoo extension.
    Download the Odoo extension (a small file called odoo.mcpb, saved in your Downloads folder)

  2. Add the file to Claude.

    Open Finder → Downloads and double-click odoo.mcpb (or drag it onto the Claude window). Claude comes to the front and asks "Install Extension? Do you want to install Odoo?".

    Nothing happened? In Claude press ⌘ , to open Settings, then Extensions → Advanced settings → Install Extension... and choose odoo.mcpb from your Downloads folder.

    In Claude press Ctrl , to open Settings, then go to Extensions → Advanced settings → Install Extension... and choose odoo.mcpb from your Downloads folder. Claude asks "Install Extension? Do you want to install Odoo?".

    Do not double-click the file in Downloads: on Windows the Claude app is not registered for .mcpb files, so Windows would ask which program to use.

  3. Click Install.

    Claude installs the extension and immediately shows its settings form (Step 3). If instead Claude says "This extension isn't signed. Ask your administrator to allow it or install a signed version.", your company's Claude settings only allow signed extensions: ask your Claude administrator to allow it or to roll it out to everyone (see For team admins), or use the automatic installer below, which does not go through the extension system.

Prefer the terminal, or also use Claude Code? Use the automatic installer instead

It downloads everything it needs, asks for your Odoo address, email and password, checks that they work, connects both Claude Desktop and Claude Code, and restarts Claude Desktop. Nothing else on your computer is changed. If you use it, Step 3 below is already done.

Open Terminal (press ⌘ space, type Terminal, press return), paste this line, press return:

3Enter your Odoo login

Right after installing, Claude shows a short form (later you find it under Settings → Extensions → Odoo). Fill it in like this and click Save.

Odoo addressAlready filled in: The address of your Odoo login page, for example https://mycompany.odoo.com. Open Odoo in your browser and copy what is in the address bar up to and including .com (or your company's domain).
Email (your Odoo login)The email you type on the Odoo login page.
Password or API keyYour Odoo password. If you log into Odoo with Google or Microsoft, or use a two-factor code, Odoo does not accept your password from other apps: use an API key instead (see below).
Database (optional)Leave empty. It is detected automatically.
Read-only modeLeave off, unless you want Claude to only look at data and never change anything.
Accept self-signed certificatesLeave off (only for internal servers with a self-signed certificate; your IT will tell you).
Open your Odoo Open your Odoo profile (API keys)
How to create an Odoo API key (for Google/Microsoft sign-in or two-factor accounts)
  1. Log into Odoo in your browser (open your Odoo profile).
  2. Click your name or avatar in the top-right corner, then Preferences (sometimes called My Profile).
  3. Open the Account Security tab and click New API Key. Odoo may ask for your password again.
  4. Give it a name like Claude, choose the longest duration offered, and click Generate key.
  5. Copy the key right away (Odoo shows it only once) and paste it into the Password or API key field in Claude. Keep using your email as the login.

When a key expires, make a new one the same way and update it in Claude under Settings → Extensions → Odoo.

4Try it

Start a new chat in Claude and ask:

Check my Odoo connection

Claude uses the Odoo tool and answers with something like:

Connected to Odoo. Address: https://mycompany.odoo.com Database: mycompany Odoo: 18.0 Enterprise User: Jane Doe (jane@mycompany.com) Company: My Company Method: web session Access: read and write

That is it. From now on, ask Claude anything about your Odoo data. If Claude asks for permission to use an Odoo tool, click Allow (or Always allow). If the answer is an error, Claude explains what to fix; the most common cases are in Something not working? below.

What can I ask Claude now?

Claude sees exactly what you can see in Odoo, nothing more, and asks before it creates, changes or deletes anything.

  • "Which invoices are overdue, and by how much in total?"
  • "Show me the open quotations for Azure Interior."
  • "How much did each salesperson sell this quarter?"
  • "Which products are below their minimum stock?"
  • "Create a lead for Acme Corp, contact Jane Doe, worth 12,000."
  • "Add a note to sales order S00042 saying the delivery is delayed."
  • "Give me a link to the customer record for Deco Addict."
  • "What fields does a sales order have?"

Something not working?

Nothing happens when I open odoo.mcpb, or Windows asks which program to use

Use Claude's own menu instead: make sure Claude Desktop (Step 1) is installed and you are signed in, press ⌘ , (Mac) or Ctrl , (Windows) to open Settings, then Extensions → Advanced settings → Install Extension... and choose the odoo.mcpb file in your Downloads folder. If Claude is very old, update it first (Settings → check for updates).

"This extension isn't signed. Ask your administrator to allow it..."

Your company's Claude administrator has switched on Require signed extensions. Two ways forward: ask the administrator to allow this extension or to upload it for the whole team (see For team admins), or use the automatic installer from Step 2, which registers the connector directly and does not use the extension system. The extension comes from your own team, not from Anthropic's store; everything it does is open source: github.com/Raiybo/Odoo-App.

"Login failed" or "needs an API key"

Use the exact email and password you type on the Odoo login page. If you sign into Odoo with Google or Microsoft, or Odoo asks you for a two-factor code, your password cannot be used by other apps: create an API key as described in Step 3 and paste it in place of the password.

"Could not determine which database to use" or "database not found"

Rare. The database name is usually the first part of your Odoo address (mycompany for mycompany.odoo.com). On Odoo.sh it is shown in your Odoo.sh project. Otherwise ask whoever manages your Odoo. Put it in the Database field (Settings → Extensions → Odoo).

Claude does not seem to know about Odoo

Fully quit Claude Desktop and open it again, then start a new chat. Check Settings → Extensions: "Odoo" must be listed and switched on. In the chat, the tools button (the sliders icon next to the message box) should list Odoo. If you used the automatic installer instead, look under Settings → Developer for a local server named "odoo"; on Windows the installer writes the configuration to both places Claude may read it from (the classic %APPDATA%\Claude folder and the Microsoft Store style Packages\Claude_...\LocalCache\Roaming\Claude folder), so re-running the installer fixes a hand-edited configuration.

My company's Claude does not allow installing extensions

On Claude Team and Enterprise plans, administrators can restrict extensions. Ask your admin to allow this one (they can upload odoo.mcpb once for everybody, see "For team admins" below), or use the automatic installer from Step 2, which does not use the extension system.

"Cannot reach Odoo" or certificate errors

If your Odoo is only reachable from the office network, connect to the VPN first. If IT told you the server uses a self-signed certificate, switch on Accept self-signed certificates in the extension settings.

Where are my Odoo password and settings stored?

On your computer only. The extension stores the password in your operating system's keychain (Claude Desktop handles that). The automatic installer stores it in a private file that only your user account can read (~/.odoo-claude/config.json on Mac, %LOCALAPPDATA%\OdooClaude\config.json on Windows). Nothing is sent anywhere except directly to your own Odoo server.

How do I remove it?

Extension: Settings → Extensions → Odoo → Uninstall. Automatic installer: run the install command again with -- --uninstall added at the end (Mac), or on Windows run $env:ODOO_CLAUDE_UNINSTALL='1' first and then the install command.

For team admins

Make a team link with your Odoo address pre-filled

Teammates who open a team link get the Odoo address filled in everywhere (even inside the extension), so they only type their email and password.

Share this link with your team (email, Slack, intranet). It never changes, so you can put it in your onboarding documents.

Roll out to everyone at once (Claude Team / Enterprise)

In the Claude admin console you can upload odoo.mcpb as a custom desktop extension and enable it for your organization; teammates then only enter their own Odoo login, and the Require signed extensions policy does not get in the way. For unattended installs on managed computers, set ODOO_URL, ODOO_LOGIN, ODOO_PASSWORD and ODOO_CLAUDE_NO_LAUNCH=1 in the environment before running the installer script; it then asks no questions and exits non-zero if the login does not work.

What this actually does (for IT and security)
  • A small local program (open source, no third-party dependencies) talks to Odoo over HTTPS using the person's own Odoo login, through Odoo's standard web API. The method is picked automatically: web session, JSON-2 API with an API key (Odoo 19+), or classic JSON-RPC. Works with Odoo Online, Odoo.sh and self-hosted Odoo, version 13 and newer.
  • The person's Odoo access rights apply unchanged. Read-only mode can be forced with ODOO_READ_ONLY=true.
  • Credentials never leave the computer except to the Odoo server. The extension keeps them in the OS keychain; the installer in a user-only file.
